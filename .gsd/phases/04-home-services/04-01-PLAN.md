# Plan 04-01: Public Marketing Website — Homepage, Services & Dynamic Showcase

**Phase:** Phase 4  
**Plan ID:** 04-01  
**Objective:** Construct a responsive, high-assurance, agency-grade homepage for VOIDTECH SOLUTION with 9 approved sections, repository integrations with safe fallbacks, accessible accordion UI, and comprehensive test coverage.

---

## 1. Work Breakdown Structure (WBS)

### Task 1: UI Primitives & Interactive Section Components
- Create `src/components/ui/accordion.tsx` (accessible, keyboard-friendly accordion primitive).
- Create `src/components/sections/service-icon.tsx` (dynamic icon mapping for all 18 services).
- Create `src/components/sections/services-filter.tsx` (Client component for filtering 18 services across 9 categories).
- Create `src/components/sections/faq-accordion.tsx` (accessible interactive FAQ client component).
- Create `src/components/sections/quick-inquiry.tsx` (direct client consultation launcher / contact anchor).

### Task 2: Homepage Implementation (`src/app/page.tsx`)
- Implement Server Component in `src/app/page.tsx` retrieving data from `ServicesRepo`, `PortfolioRepo`, `PricingRepo`, and `FaqRepo`.
- Implement Section 1: Hero ("Turning Ideas Into Powerful Digital Products.").
- Implement Section 2: Brand Introduction.
- Implement Section 3: Services Showcase (all 18 approved services with Lucide icons, INR prices, tech tags).
- Implement Section 4: Why Choose VoidTech (6 practical engineering differentiators).
- Implement Section 5: Development Process (7-stage timeline).
- Implement Section 6: Featured Projects (PortfolioRepo concept prototypes with CONCEPT label).
- Implement Section 7: Pricing Preview (10 approved starting prices in INR).
- Implement Section 8: FAQ Preview (accessible accordion with FaqRepo data).
- Implement Section 9: Final CTA ("Have an Idea? Let's Build It.").

### Task 3: SEO, Metadata & Accessibility
- Configure complete OpenGraph and Twitter card metadata for `src/app/page.tsx`.
- Semantic landmarks (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`).
- Contrast ratios compliant with WCAG AA standard on `#050507` background.
- Respect `prefers-reduced-motion` in animations.

### Task 4: Testing & Empirical Verification
- Author comprehensive unit & integration tests in `tests/unit/homepage.test.tsx`:
  - Hero rendering, typography, and CTA links.
  - Brand introduction message.
  - Services showcase rendering all 18 services, categories, and INR prices.
  - Why Choose VoidTech 6 pillars.
  - 7-stage development process.
  - Featured projects with CONCEPT badge.
  - 10 approved INR pricing tiers (₹999 to ₹59,999+) with `+` signs.
  - FAQ accordion keyboard interactions and ARIA attributes.
  - Final CTA block.
  - Graceful fallback behavior when database tables are empty.

### Task 5: Quality Gate & Documentation
- Run `npm run typecheck` (`tsc --noEmit`).
- Run `npm run lint` (`next lint`).
- Run `npm test` (`vitest run`).
- Run `npm run build` (`next build`).
- Update `.gsd/STATE.md`, `.gsd/ROADMAP.md`, `.gsd/TODO.md`, `docs/PROJECT_STATUS.md`, `docs/CHANGELOG.md`.
- Produce Phase 4 Summary (`04-01-SUMMARY.md`) and Verification Report (`VERIFICATION.md`).
- Strict Stop Condition: Await user approval before proceeding further.
