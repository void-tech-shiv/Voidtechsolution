### B. Dedicated Portfolio Listing Page (`src/app/portfolio/page.tsx`)
- [ ] Hero Banner
  - Headline: *"Selected Work & Engineering Concepts."*
  - Supporting text: *"Explore software concepts, architecture experiments and digital solutions developed around practical engineering challenges."*
- [ ] Data integration via `PortfolioRepo.getAllProjects()` with fail-safe fallback.
- [ ] Client component `PortfolioFilter` (`src/components/sections/portfolio-filter.tsx`):
  - Category pill filter: All, FinTech, DevOps & AI, Data Engineering, IoT & Real-time.
  - Live full-text search input (filters title, summary, tech stack).
  - Clear filter button & active count indicator.
  - Empty state with reset action when no projects match.
- [ ] Project Cards:
  - Title, summary, category/industry tag.
  - Classification badge (`CONCEPT`, `CLIENT PROJECT`, `OPEN SOURCE`).

- [ ] `generateMetadata()` for dynamic title, description, and OpenGraph.
- [ ] Safe 404 via `notFound()` for invalid slugs.
- [ ] Rich Case Study Layout:
  1. Breadcrumbs: `Home / Portfolio / [Title]`
  2. Hero: Title, category, classification badge (`CONCEPT`), tech stack, simulated metrics.
  3. Project Overview: High-level purpose and engineering scope.
  4. Problem or Opportunity: Explicitly hypothetical for concept prototypes.

  7. Technical Highlights: Performance, scalability, security, and maintainability.
  8. Visual Architecture / Gallery: Responsive stylized architecture diagram and UI preview cards.

  10. Simulated Benchmarks: Explicitly marked `SIMULATED BENCHMARK`.
  11. Related Projects: Carousel/grid of other concept case studies.
  12. Closing CTA: *"Ready to Build Your Solution?"* &rarr; `/#contact`.
